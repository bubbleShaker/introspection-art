# 音源の置き場所

このディレクトリに `introspection.mp3` を置くと、サイトが起動時に読み込みます。

```
public/audio/introspection.mp3
```

置かれていない場合でも画面は成立します（水面はひとりでに揺れます）。
その状態で mp3 を画面にドラッグ&ドロップすれば、その曲に反応します。

## 音源について

- 曲名: Introspection
- 作者: Mona Wonderlick
- 出典: <https://youtu.be/UZzuVt7nKOA>（YouTube Audio Library 経由のフリー BGM）
- 公式の無料ダウンロード: <https://hypeddit.com/track/y190y1>

利用にあたっては作者へのクレジット表示が必要で、サイト下部に記載している。
