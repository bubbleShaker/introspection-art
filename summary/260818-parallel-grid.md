# 綺麗な球を、平行な格子で包んでゆっくり回す

[Issue #19](https://github.com/bubbleShaker/introspection-art/issues/19)

## 何をしたか

[#17](https://github.com/bubbleShaker/introspection-art/issues/17) までの球は、
波形が半径を膨らませ、3 次元ノイズが線を押し曲げていたので、輪郭も線もヨレて
見えていた。線は緯線・経線で、経線は必ず上下の極（一点）へ集まっていた。

形を歪めるのをやめて**完全な球**にし、線を**互いに平行な平面で切った円**の
二組に置き換え、半透明にして、ゆっくり回した。

| | 前（#17） | 後 |
| --- | --- | --- |
| 輪郭 | 波形で半径が ±12% 揺れる | 真円。低域で一様に +6% まで膨らむ |
| 線の引き方 | 緯線 8 / 経線 12（極へ集まる） | 平行な平面で切った円、縦横 7 本ずつ |
| 線の歪み | `fbm3` のうねりで押し曲げる | 歪めない |
| 線の濃さ | 不透明（覆いきると白） | 半透明（`WIRE_ALPHA = 0.55`） |
| 姿勢 | 固定 | 視線の軸まわりに回り、他の 2 軸は揺れる |
| 音の出どころ | 半径の膨らみ・緯線の押し上げ | 線の濃さ・呼吸・回る速さ |
| 交差判定 | 2 段階に切り直す | 二次方程式 1 本 |

## 設計 1: 平行な平面で切ると、極が無くなる

緯度経度が「一点から一点へ結ぶ」形になるのは、経線が極で必ず束ねられるため。
そこで、**ひとつの軸に垂直な平面群**で球を切る。平面はどれも互いに平行なので、
切り口の円も互いに交わらない。これを軸ふたつぶん（格子の x と y）重ねる。

```
  ┌ ─ ─ ─ ─ ─ ┐
 ╱ │ │ │ │ │ ╲     縦線 = 格子の x が一定の円
│──┼─┼─┼─┼─┼──│    横線 = 格子の y が一定の円
│──┼─┼─┼─┼─┼──│    どちらの家族も、束ねられる点を持たない
 ╲ │ │ │ │ │ ╱
  └ ─ ─ ─ ─ ─ ┘
```

肝は**線をどの座標で等間隔に並べるか**である。軸方向の成分 `s`（-1..1）のまま
等間隔に切ると、画面では等間隔に並ぶが球面上では端ほど間延びして、丸みが
消えて方眼紙に見える。`asin(s)` で切ると、これは球面上の弧の長さそのもの
（この向きの傾きがどこでも 1 になる）なので、**球の上で等間隔＝画面では端ほど
詰まる**になり、平行な線のまま丸みが出る。

```glsl
float gridLines(float s, float count, float aa, float fade) {
  float arc = asin(clamp(s, -1.0, 1.0));
  return wireLine(arc * count / PI, PI / count, aa, fade);
}
```

線の太さと滲みは球面上の長さで測っているので、間隔（`PI / count`）を長さの
まま書き切れるのも `asin` のおかげ。緯度経度の頃は、経線の間隔が緯度で変わる
ぶんを `TAU * around / WIRE_MERIDIANS` と補正していた。

副産物として、`atan()` の継ぎ目（経度 ±0.5 で `fract` が飛ぶ）と、極での
`atan(0, 0)` の未定義（NaN がブルームに拾われて面へ広がる）が、**線の位置を
決める側からは**消えた。`asin` はどこまでも連続している。`atan` は波形の輪
（`waveAt`）に残っているが、こちらは濃さを決めるだけで、ガードも据え置き。

## 設計 2: 回す軸を選ぶ

回転させて最初に出てきたのは、**格子が同心円に化ける**という絵だった。

線が平行に見えるのは、格子の軸が画面の面に寝ている（＝切り口の平面を横から
見ている）あいだだけである。軸がこちらを向くと、その家族の円は正面から見た
輪になり、まとめて同心円として現れる。3 軸を等しく回すと、この姿勢を必ず
通過する。

```
軸が画面の面に寝ている        軸がこちらを向いている
    │ │ │ │ │                    ╭───╮
   ─┼─┼─┼─┼─┼─                  ( ((○)) )
    │ │ │ │ │                    ╰───╯
    平行な線                      同心円
```

そこで、**視線の軸（z）まわりだけを回し切り、残る 2 軸は振れ幅を抑えて揺らす**
に留めた。z まわりの回転は軸を画面の面から起こさないので、格子は平行なまま
風車のように回り、他の 2 軸の揺れがそこへ立体の転がりを足す。

```glsl
float ax = sin(t * 0.19) * 0.42;              // ±24°。回し切らない
float ay = sin(t * 0.13 + 2.2) * 0.38;        // ±22°
float az = t * 0.30 + sin(t * 0.11) * 0.5;    // ここだけ回し切る
return rx * ry * rz;                          // rz が先（q に最初に当たる）
```

**掛ける順で結果が変わる**。`rx * ry * rz` と書くと、格子の x 軸の面外成分が
ちょうど `sin(ay)`、y 軸が `sin(ax)` になり、振れ幅がそのまま「軸が画面の面から
起きる角度」の上限として効く（実測 21.8° / 24.1°）。

逆に `rz * ry * rx` と書くと、面内の回転が揺れを画面の外へ持ち出す向きにも
回してしまい、面外角は `sqrt(sin²ax + cos²ax·sin²ay)` まで開く。**同じ振れ幅の
まま 24° が 32° になり、線が輪に見える姿勢が出てくる**。最初はこの順で書いて
いて、レビューで気付いた。

回した量（`uSpin`）は JS 側で積み上げて渡す。速さを音で変えるものに時刻の
係数を掛けてはいけない、という `uTime` と同じ作法（`sin(t * k)` の `k` を動かすと
`t` が大きいほど位相が飛ぶ）。

## 設計 3: 音は形ではなく濃さへ

半径のヨレを取ると球が音に反応しなくなるので、反応を三つへ移した。

| 反応 | 出どころ | 効き方 |
| --- | --- | --- |
| 線の濃さ | `waveAt()`（波形の輪） | 波形の強い向きの線が、その場で明るくなる |
| 一様な呼吸 | `uLow` | 半径が向きに依らず +6% まで膨らむ（真円のまま） |
| 回る速さ | `uLow` | `SPIN_IDLE = 0.5` に最大 `SPIN_GAIN = 1.1` が乗る |

`waveSphere.ts`（波形を輪へ畳む純粋計算）の**振る舞いは変えていない**
（doc だけ、値の行き先に合わせて直した）。輪の値の行き先が「半径の膨らみ」から
「線の濃さ」に変わっただけで、`WAVE_POINTS` をシェーダーと突き合わせる
テストもそのまま生きている。

## 消えたもの

- `SPHERE_SWING` / `sphereRadiusAt()` / `sphereSurfaceHit()` — 半径が向きに
  依らなくなり、交差は二次方程式 1 本に戻った
- `hash31()` / `valueNoise3()` / `fbm3()` — 球のうねり専用だったので、まるごと落ちた
- `WIRE_MERIDIANS` / `WIRE_PARALLELS` / `WIRE_RIB` / `SPHERE_WARP_FREQ`

## 確かめたこと

`npm run build` / `npm test`（76 件）/ `npm run lint` を通した。

見た目は Playwright で撮って確かめている。**揺れが最大になる時刻を狙う**のが
肝で、`ax` は `uSpin = 8.3`、`ay` は `uSpin = 19.3` で振れ切る（無音では
`SPIN_IDLE = 0.5` なので実時間 16.6 秒 / 38.6 秒）。そこを含む 4 つの姿勢で、
**線が同心円へ化けない**ことを見た。最初に撮った時はここを外していて、
面外角が開いていることに気付けなかった。

音への反応は、低域の強い試験音（ffmpeg で作った 55 Hz のトレモロ）を
ドロップして、線ごとの明るさが動くことを確かめた。

## 二つのファイルに跨がる取り決め

回転の周期は `SPIN_IDLE`（`glScene.ts`）と `az` の係数（`scene.frag.glsl`）の
両方で決まる。`WIRE_COLOR` × ブルームの閾値と同じ構図で、片方だけ動かしても
例外は出ず、速さが黙って変わる。`tests/spinPeriod.test.ts` がシェーダーの原文を
読んで、周期が曲に合う範囲（30〜60 秒）に収まることを確かめている。
格子の本数が奇数であること（偶数だと軸が球を貫く点に線が乗ってちらつく）も、
同じ形で留めた。
