# 格子を、白い線だけの手前のレイヤにした

[Issue #17](https://github.com/bubbleShaker/introspection-art/issues/17)

## 何をしたか

[#15](https://github.com/bubbleShaker/introspection-art/issues/15) で球を格子に
したが、線はまだ**世界の中の物体**だった。`skyColor()` を反射で引き、フレネルで
混ぜ、月の鏡面反射を足し、縁を強調していた。結果として線は青く沈み、輪郭では
薄い帯に溶け、ブルームで滲んでいた。

それをやめて、**世界の光を受けない白い線画**にした。

| | 前（#15） | 後 |
| --- | --- | --- |
| 線の色 | 空の反射＋フレネル＋月の鏡面反射 | 白の一定色 `vec3(0.95)` |
| 格子の目 | 経線 20 / 緯線 12 | 経線 12 / 緯線 8 |
| 線の太さ | 0.010 | 0.005 |
| 輪郭の潰れた線 | 薄い帯として残す | 薄れて消える |
| 向こう側の線の濃さ | 0.30 | 0.35（線が細くなったぶん戻した） |
| 水面への映り込み | あり | 無し |
| ブルーム | 線も滲む | 閾値の下に置いて滲ませない |

## 設計: 色を返さなくなった

線の色が「どこを見ても同じ白」になったので、球の描画から**色そのものが
消えた**。`sphereWire()` が返すのは覆い（0..1）1 本だけになり、色は呼ぶ側が
一定値で持つ。

```glsl
col = mix(col, WIRE_COLOR, sphereWire(ro, rd));
```

前は「表と裏、それぞれの色を覆いで重み付けして混ぜ、合計の覆いで割り戻す」
という premultiplied の合成をしていた。色が同じなら、合成は覆いの足し算に
畳める。

```glsl
return front + back * (1.0 - front);
```

`wireColor()` / `WIRE_BODY` / `WIRE_GLOW` / `WIRE_SPEC` は消えた。
球のピクセルから `skyColor()` の呼び出しが無くなったので、負荷も下がっている
（#15 のレビューで「最悪 1 ピクセル 5 回」と言われた `skyColor()` は、
反射経路の 1 回だけになった）。

## 「手前のレイヤ」をどう作るか

三つの手当てで出している。物として置いたものを浮かせるのではなく、
**世界と噛み合う経路を全部外す**という向きの作業だった。

1. **空を映さない** — `skyColor()` を引かない。後ろが何であれ線は同じ白
2. **水面に映らない** — 水面の反射レイから球の交差判定を外した。
   水面が映すのは空だけになる
3. **滲まない** — `WIRE_COLOR = 0.95` は、出力の圧縮 `col / (1 + col)` を
   通ると輝度 0.487 になり、`bloom.frag` の `THRESHOLD = 0.52` の下に収まる。
   線がブルームに拾われないので、線画のまま残る

3 番目が効いた。ブルームは「明るい画素を集めて散らす」ので、白い線を素直に
明るくすると、線のまわりが煙のように光って**線が線でなくなる**。閾値の
すぐ下という置き場所が、白さと線らしさの両立点になっている。

## 滲みは、階段を消すぶんだけ

線を細くすると、アンチエイリアスの幅がそのまま「ぼやけ」として見えてくる。
#15 は滲みと薄めを一つの `aa` から出していたので、輪郭をぼかさないように
頭を押さえると、薄める方も一緒に効かなくなる（レビューで指摘された）。

**別々に出すようにした。**

```glsl
float grazing = spread / max(abs(dot(rd, q)), 0.03);  // 実際の潰れ具合
float aa   = min(grazing, spread * 3.0);              // 滲ませるのは階段を消すぶんまで
float fade = min(1.0, WIRE_WIDTH * 3.0 / grazing);    // 薄めるのは潰れたぶんだけ
```

滲みは 1 ピクセルの数倍で頭打ちにし、薄めは頭打ちにしない。輪郭の線は
ぼやけずに薄れて消える。あわせて、潰れた線を薄い帯として残していた下限
（`mix(0.34, 1.0, ...)`）を撤廃した。線だけで形を出すなら、見えない線は
消してよい。

極のすぐ際の緯線も落とした（`smoothstep(0.0, 0.10, around)`）。輪が点に
縮んで、画面では白い粒にしかならない。

## 触っていないもの

`src/audio/`, `src/core/`, `src/scene/waveSphere.ts`、水面と空の描画。
`skyColor()` を空と水面の反射で共用する構造は、そのまま残っている。
外れたのは球だけ。

## 二つのファイルに跨がる約束を、テストで留めた

「線がブルームに拾われない」は `scene.frag` の `WIRE_COLOR` と `bloom.frag` の
`THRESHOLD` の関係だけで成り立っていて、片方を動かすと例外も警告も出ないまま
見え方が変わる。`tests/wireBrightness.test.ts` が両方の原文から定数を読み、
`WIRE_COLOR / (1 + WIRE_COLOR) < THRESHOLD` を確かめている
（`waveSphere.test.ts` がシェーダーの `WAVE_POINTS` を見ているのと同じやり方）。
